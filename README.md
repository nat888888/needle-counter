# マイクロニードル画像解析ツール

マイクロニードルの顕微鏡画像を解析するプログラムです。
以下の3つを自動で行います。

- 画像内の針を検出して本数を数える
- 先端が丸まった「欠損針」を判定してカウントする
- 各針の「高さ」と「底辺の長さ」を測定する（最大の針を1とした無次元値）

---

## 動作環境

- Python 3.9 以上
- macOS / Linux で動作確認済み

---

## はじめての方へ：ダウンロードから実行まで

ターミナルを開いて、上から順にコマンドを実行してください。

### 手順1：このプロジェクトをダウンロードする

プロジェクト一式を自分のパソコンにコピーします。

```bash
git clone https://github.com/natsu888888/needle-counter.git
cd needle-counter
```

もしGitを使わない場合は、「Code」ボタン →「Download ZIP」でzipファイルとしてダウンロードし、
解凍してからそのフォルダに移動してもかまいません。

### 手順2：仮想環境を作る

「仮想環境」を作ることで、パソコン全体の設定を汚さずに、必要な道具だけをそろえられます。

```bash
python3 -m venv venv
source venv/bin/activate
```

2行目を実行すると、ターミナルの行頭に `(venv)` と表示されます。
これが「仮想環境に入っている」目印です。

> 作業をやめて仮想環境から出たいときは `deactivate` と入力します。
> 次に作業を再開するときは、プロジェクトのフォルダで `source venv/bin/activate` をもう一度実行してください。

### 手順3：必要なライブラリをインストールする

このプログラムが使うライブラリをまとめて入れます。

```bash
pip install -r requirements.txt
```

### 手順4：解析したい画像を置く

サンプル画像はこのリポジトリには含まれていません（機密性のため）。
別途、使用する画像を、`images` フォルダを作ってその中に置いてください。

```bash
mkdir -p images
```

画像を `images/sample.jpg` という名前で置くと、そのまま実行できます。
別の名前にする場合は、次の手順で開くノートブックの中の
`IMAGE_PATH` という部分を、その画像の名前に書き換えてください。

### 手順5：プログラムを実行する

このプロジェクトは「Jupyter Notebook」という形式で作られています。
コードを少しずつ実行して、途中経過を画像で確認しながら進められるものです。

```bash
jupyter notebook
```

実行するとブラウザが自動で開きます。
`notebooks` フォルダの中の `analysis.ipynb` をクリックして開いてください。

ノートブックが開いたら、上のセルから順番に、1つずつ実行していきます。
一番上から順に実行すると、最後に解析結果が表示されます。

## 処理の流れ

プログラムは大きく6つのステップで動いています。

1. グレースケール化 … カラー画像を明るさだけの白黒画像に変換する
2. スケールバーの除去 … 画像下部の縮尺バーを解析対象から外す
3. 針の検出 … 画像から針を1つずつ探し出す
4. 輪郭の抽出 … 各針の輪郭線を取り出す
5. 先端の尖り具合の算出 … 先端が尖っているか丸まっているかを数値化する
6. 欠損の判定・寸法の測定 … 欠損針を数え、各針の高さと底辺を測る

---

## 注意点・現在の制限

- 針の先端が画像の**左側**にある前提で作られています。別の向きの画像には現時点では対応していません。
- 画像の**縮尺**は現在のサンプル画像に合わせています。縮尺の違う画像への対応は今後の課題です。
- 針の底辺は画像上にはっきりした境界線として写らないため、底辺付近の測定精度はやや低めです。
- 欠損の判定は100%の正確さを目指したものではありません（おおよそ8〜9割の判定を想定）。
- 機械学習は使用していません。
